➕ Add New Facebook Page

You can add as many pages as you want (Page 16, 17, 20+). All pages are automatically managed by the automation pipeline and displayed here in real time.

How to add a new page:
  1. Open your Facebook profile and create or switch to the new Page.
  2. Add the Page ID and Permanent Token to pages_tokens.json.
  3. Add the Page entry in config.yaml with its Google Drive folder ID.
  4. Run python scripts/sync_dashboard_data.py or push to GitHub.
