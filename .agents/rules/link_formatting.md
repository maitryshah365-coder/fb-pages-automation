# User Preference: Direct Copy-Paste Links

Whenever providing URLs or web links to the user:
1. Always provide direct, unmasked, raw URLs formatted in copy-pasteable code blocks (e.g. `https://...`).
2. Do not use masked markdown anchor text alone (e.g. avoid only writing [Click Here](url)). Always provide the full, literal URL so the user can easily copy and paste it into the browser address bar.
3. Keep instructions step-by-step with the exact URL prominently displayed right beneath each step.
