Privacy Policy

Last updated: September 17, 2026

This Privacy Policy describes how the Facebook Pages Automation System ("we", "our", or "the Application") collects, uses, and protects your information when interacting with Meta's Graph API and Facebook Pages services.

1. Information We Access

Our application interacts with the Meta Graph API solely to perform authorized page management tasks on behalf of the page administrator. We access:

  • Basic public profile information and Page metadata (Page Name, Page ID, Category).
  • Page insights, reach, and performance metrics (Views, Likes, Comments, Audience retention).
  • Uploaded video content and status for scheduling and publishing Reels.

2. How We Use the Information

The accessed information is strictly used for:

  • Automating the publication of video Reels directly to authorized Facebook Pages.
  • Displaying performance metrics and analytics on the private operator dashboard.
  • Ensuring optimal delivery and tracking content reach for content creators.

3. Data Sharing & Third Parties

We do NOT sell, rent, trade, or share any personal information, access tokens, or page content with third-party advertisers or external data brokers. All data remains strictly within the secure cloud automation pipeline.

4. Data Storage & Security

Access tokens are stored in secure encrypted environment secrets. Video files are queued via Google Drive and automatically processed through encrypted HTTPS connections directly to Meta Graph API endpoints.

5. Data Deletion Rights

Users have the right to request deletion of any data held by our application at any time. For instructions on data deletion, please visit our User Data Deletion Page or remove app permissions directly via Facebook Account Settings.
